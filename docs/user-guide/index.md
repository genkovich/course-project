# Meme Generator — user guide

The Meme Generator makes a meme in two clicks: pick a random template with a
caption, then save it to a shared gallery you can browse and filter by tag.

This guide is written for using the app, not building it. For the developer-facing
API, see [`docs/api.md`](../api.md).

## Guides

- **[Generating a meme](generating-a-meme.md)** — create a meme and save it to the gallery.
- **[Filtering by tag](filtering-by-tag.md)** — narrow the gallery down to one tag.
